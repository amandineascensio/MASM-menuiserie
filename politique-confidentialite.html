Politique de confidentialité

1. Responsable du traitement

Le responsable du traitement des données personnelles est MASM Menuiserie, situé Allée Camille Pissarro, 77410 Annet-sur-Marne.

Email : contact.masmlozano@gmail.com

2. Données collectées

Nous collectons les données suivantes via le formulaire de demande de devis :

  • Nom
  • Adresse email
  • Description du projet

Les avis laissés sur le site collectent :

  • Nom ou pseudonyme
  • Contenu de l'avis

3. Finalité du traitement

Les données collectées sont utilisées pour :

  • Répondre à vos demandes de devis
  • Vous recontacter dans le cadre de votre projet
  • Afficher les avis clients sur le site

4. Base légale

Le traitement des données repose sur votre consentement (article 6.1.a du RGPD) lors de la soumission du formulaire de contact ou d'avis.

5. Durée de conservation

Les données collectées via le formulaire de devis sont conservées pendant une durée de 3 ans à compter du dernier contact. Les avis sont conservés tant que le site est en ligne, sauf demande de suppression.

6. Destinataires des données

Vos données personnelles ne sont transmises à aucun tiers. Elles sont uniquement utilisées par MASM Menuiserie dans le cadre décrit ci-dessus.

7. Vos droits

Conformément au RGPD, vous disposez des droits suivants :

  • Droit d'accès : obtenir une copie de vos données
  • Droit de rectification : corriger vos données
  • Droit à l'effacement : demander la suppression de vos données
  • Droit d'opposition : vous opposer au traitement
  • Droit à la portabilité : récupérer vos données dans un format lisible

Pour exercer ces droits, contactez-nous à : contact.masmlozano@gmail.com

8. Cookies

Ce site utilise uniquement des cookies fonctionnels nécessaires au bon fonctionnement du site (stockage des avis en local). Aucun cookie publicitaire ou de suivi n'est utilisé.

Google Maps, intégré dans le footer, peut déposer ses propres cookies. Pour en savoir plus, consultez la politique de confidentialité de Google.

9. Réclamation

Si vous estimez que le traitement de vos données ne respecte pas la réglementation, vous pouvez adresser une réclamation à la CNIL (Commission Nationale de l'Informatique et des Libertés) : www.cnil.fr
